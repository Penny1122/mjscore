# 麻將記分系統 需求規格

## 目的

用 React + TypeScript + Tailwind 做一個網頁工具，記錄**台灣麻將**每一場結束後的最終分數，並保存歷史紀錄。

本工具只記「最終結果」，不做逐把計台。

## 名詞定義

| 名詞 | 說明 |
| --- | --- |
| 一筆紀錄 | 一次聚會/一場牌局結束後的結算結果 |
| 將 | 台灣麻將的計量單位，一將 = 四圈（東、南、西、北風圈） |
| 打幾將 | 該玩家在這筆紀錄中實際上桌打了幾將 |
| 東錢 | 抽給場地/東家的錢，不計入任何玩家的勝負與名次，也不納入分析；可選擇是否算進「加總為 0」的檢查 |
| 總將數 | 這筆紀錄中玩家將數的最大值，例：4 人都打 3 將，總將數為 3 將 |

## 功能需求

### 1. 新增紀錄

- 輸入日期（預設今天）。
- 選擇場地（選填）：從場地名單點選，或直接輸入新場地；預設帶入最近一次用過的場地。
- 輸入玩家，**人數至少 4 人，可超過 4 人**（換人輪流上桌的情況）。
  - 可新增、移除玩家列。
  - 每位玩家輸入：
    - 名字（必填）：可從「牌咖」名單直接點選，也可手動輸入新名字
    - 最終分數（必填，單位為**元**，整數，可為負數）
    - 打幾將（必填，正整數）
- 輸入東錢（選填，單位為元，非負整數，整筆紀錄一個數字）。
- 「東錢計入加總」開關（預設關閉），每筆紀錄各自設定。
- 輸入時即時預覽名次與分數總和。

### 2. 驗證規則

存檔前檢查：

- 玩家人數 ≥ 4。
- 每位玩家名字、分數、將數都已填寫且格式正確。
- 同一筆紀錄內玩家名字不可重複。
- **加總必須為 0**，不為 0 時顯示差額且不能存檔：
  - 東錢不計入加總（預設）：所有玩家金額加總 = 0。
  - 東錢計入加總：所有玩家金額加總 + 東錢 = 0。例：東錢 400，玩家合計需為 -400。
- 不論是否計入加總，東錢都不影響名次。

### 3. 自動排序名次

- 依最終分數由高到低排序。
- 同分者名次相同，下一名次跳號。例：

  ```text
  +1200 → 第 1 名
  +1200 → 第 1 名
   -800 → 第 3 名
  -1600 → 第 4 名
  ```

### 4. 儲存紀錄

- 紀錄存於 Supabase 雲端資料庫，換裝置也看得到（設計見 [supabase-design.md](supabase-design.md)）。
- 第一版存在瀏覽器 localStorage 的舊紀錄不匯入（只是測試資料）。
- 存檔後顯示該筆的排名結果。

### 5. 牌咖與場地名單

「名單」頁分「牌咖」與「場地」兩個分頁。

**牌咖**

- 可手動新增牌咖（還沒上過桌的顯示「尚未上桌」）。
- 存檔時，這筆紀錄裡的玩家名字也會自動加入牌咖名單。
- 新增紀錄時，名字欄位聚焦後顯示牌咖，點一下即可帶入。
  - 最近上過桌的排前面，還沒上過桌的依新增時間排在後面。
  - 已經在這筆紀錄中被選過的名字不再重複顯示。
- 名字欄位輸入文字時，即時篩選符合的牌咖。

**場地**

- 可手動新增場地（還沒用過的顯示「尚未使用」）。
- 記錄時輸入不在名單中的場地，存檔後自動加入場地名單。
- 新增紀錄時，場地欄位下方顯示場地名單，點一下即可選擇，再點一次取消。
- 最近用過的場地排前面。

**共同規則**

- 名字最多 30 個字，前後空白會自動去除，名單內不可重複。
- 可從名單刪除（需二次確認），不影響已存的紀錄。
- 唯讀時只能看名單，不能新增、刪除。

### 6. 總覽（首頁）

一進來顯示總覽，唯讀也看得到。

- 摘要：總場數、總將數（每筆取最高將數再加總）、最近一場日期。
- 戰績排行，依總分高到低，同分同名次。每位牌咖顯示：
  - 總分：所有紀錄金額加總，不含東錢
  - 場數：出現在幾筆紀錄
  - 總將數：此人每筆紀錄的將數加總
  - 勝率：贏錢（金額 > 0）場數 ÷ 出場場數；0 元不算贏
  - 每將平均：總分 ÷ 總將數，四捨五入
- 牌咖、場地各一張卡片，名單以標籤顯示，標籤上標出場數。

### 6-1. 查看歷史紀錄

- 依日期新到舊排列。
- 以**卡片**呈現，每張卡片顯示：
  - 日期、場地（有選才顯示）
  - 第一名玩家與分數
  - 所有玩家名次、分數、將數
  - 東錢（有填才顯示）
- 點卡片可查看完整內容。
- 可刪除紀錄（需二次確認）。

### 7. 編輯紀錄

- 從紀錄明細進入編輯，使用與新增紀錄相同的表單，帶入原本的資料。
- 可修改日期、場地、玩家（含增減人數）、分數、將數、東錢。
- 可修改「東錢計入加總」設定。
- 驗證規則與新增相同，加總必須為 0 才能存檔。
- 存檔後更新 `updatedAt`，`createdAt` 不變。
- 可取消編輯，回到明細且不變動資料。

### 8. 分享與唯讀

- 分享網址給其他人，任何人都能看歷史紀錄與明細。
- 預設為唯讀，輸入編輯密碼才能解除唯讀，解鎖後才能新增、編輯、刪除。
- 不做帳號登入，所有可編輯的人共用一組密碼。
- 解鎖後該裝置會記住，可手動鎖定。

## 畫面需求

- **手機優先**：以約 375–430px 寬設計，桌機再放寬版面。
- **先做深色模式**：MVP 只做深色主題，淺色之後再補。
- 數字輸入框要大、好點，叫出數字鍵盤（`inputMode="numeric"`，需能輸入負號）。
- 金額顯示加上正負號，不加千分位，例：`+1200`、`-800`。
- 正分、負分用不同顏色區分（例：正分綠、負分紅）。
- 加總不為 0 時，在畫面上明顯提示。東錢計入加總時，顯示「玩家合計 ＋ 東錢」。

### 頁面

| 頁面 | 內容 |
| --- | --- |
| 總覽 | 摘要、戰績排行、牌咖與場地標籤 |
| 新增紀錄 | 日期、場地與場地快選、玩家列表（名字／分數／將數）、牌咖快選、東錢與「計入加總」開關、即時排名預覽、存檔按鈕 |
| 編輯紀錄 | 同新增紀錄表單，帶入既有資料，另有取消按鈕 |
| 歷史紀錄 | 卡片列表 |
| 紀錄明細 | 單筆完整結果、場地、東錢（含是否計入加總）、總將數、編輯按鈕、刪除按鈕 |
| 名單 | 牌咖／場地兩個分頁，新增與刪除 |
| 設定 | 更改編輯密碼、鎖定此裝置 |
| 解鎖 | 輸入編輯密碼 |

MVP 先用 React state 切換頁面，不引入 router。

## 資料結構

```ts
type PlayerResult = {
  id: string
  name: string
  score: number    // 最終金額（元），所有玩家加總必須為 0
  rounds: number   // 打幾將
}

type GameRecord = {
  id: string
  date: string         // YYYY-MM-DD
  venue?: string       // 場地，未指定為 undefined
  players: PlayerResult[]
  houseFee?: number    // 東錢（元），整筆一個數字，不計入勝負
  houseFeeInTotal?: boolean // 東錢是否算進加總為 0，未設定視為 false
  createdAt: string
  updatedAt: string
}

type RankedPlayerResult = PlayerResult & {
  rank: number
  isTied: boolean
}

// 牌咖名單
type KnownPlayer = {
  name: string
  lastPlayedAt: string | null // 最近上桌時間；手動新增、還沒上過桌為 null
}

// 場地名單
type Venue = {
  name: string
  lastUsedAt: string | null   // 最近使用時間；還沒用過為 null
}
```

第一版的 localStorage key（雲端版改用 Supabase 資料表，見 [supabase-design.md](supabase-design.md)）：

- `mjscore.records`：所有紀錄
- `mjscore.players`：常用玩家名單

## 不在本次範圍

- 逐把計台、自動算台數
- 帳號登入、每個人不同權限
- 即時同步（別人存檔後要重新整理才看得到）
- 進階統計（依場地或期間篩選、個人趨勢圖）
- 淺色模式

## 實作步驟

1. **型別與工具函式**：型別定義、排名計算、驗證、localStorage 存取。
2. **新增紀錄頁**：動態玩家列、常用玩家快選、即時總和與排名預覽、存檔。
3. **歷史紀錄頁**：卡片列表、明細、刪除。
4. **編輯紀錄**：重用新增表單，帶入既有資料。
5. **瀏覽器驗證**（Playwright）：手機寬度下新增一筆超過 4 人的紀錄、總和不為 0 時無法存檔、常用玩家可點選帶入、編輯後資料正確、重新整理後歷史紀錄仍在。

## 已確認

- 東錢為整筆紀錄一個數字，不分玩家記錄。
- 東錢可選擇是否計入加總為 0。
- 總將數為紀錄中最高的將數，不是加總。
- 紀錄改存 Supabase。
- 分享給別人觀看；輸入密碼才能解除唯讀，不做登入。
- 最終分數記的是金額（元），顯示不加千分位。
- 要記住玩家名字，下次可直接點選。
- 可以手動新增牌咖與場地；記錄時可選擇場地（選填）。
- 首頁為總覽：戰績排行（總分、場數、總將數、勝率、每將平均）與牌咖、場地標籤。
- 已存的紀錄可以編輯。
